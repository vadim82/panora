Install Panora on Omarchy

Panora rotates wallpapers from your active theme, local folders, and saved Wallhaven searches. This package targets Omarchy on Arch Linux x86-64.

Add the Panora package repository

Download the Panora public key and verify this fingerprint before trusting it.

gpg --show-keys --fingerprint ./panora-signing-key.asc

Expected fingerprint 8E2A 94B8 A2B9 1252 C5B3 47FF 7879 56F9 04D9 C8B6

After verifying the fingerprint, add the key to your pacman keyring and trust it locally.

sudo pacman-key --add ./panora-signing-key.asc
sudo pacman-key --lsign-key 8E2A94B8A2B91252C5B347FF787956F904D9C8B6

If you added the original v0.7.0 key, download the current public key and run sudo pacman-key --add ./panora-signing-key.asc again before upgrading. The updated certificate includes the release signing subkey and keeps the same primary fingerprint.

Append this repository entry to /etc/pacman.conf. Panora requires valid signatures for packages and the repository database.

[panora]
SigLevel = Required TrustedOnly
Server = https://vadim82.github.io/panora/arch/$arch

Find, install, and update

Run Update → Omarchy to sync the repository with the rest of your system. You can then find and install Panora.

yay -Ss panora
yay -S panora

Open Panora from the launcher. On Omarchy 4.5, its service adds a bar button on first use. Use Update → Omarchy for future upgrades. If you refresh your pacman configuration, restore the Panora entry or arrange to reapply it with the pre-refresh-pacman hook.
