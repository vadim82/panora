# Wallhaven tag suggestions

Open **Filters → Tags** to see popular tags, or type in **Tag name** to find
a matching prefix. Select a suggestion, or enter any valid tag name and press
Enter. **Browse Wallhaven tags** opens the full catalog in your browser.

Suggestions use the first 100 tag names from Wallhaven’s **Most Tagged**
ranking, captured November 23, 2026. The snapshot follows Wallhaven’s order and
includes mixed-purity tag names. The picker shows up to ten matching tags in
rank order and skips tags already selected, regardless of capitalization.
Wallhaven search results in Panora remain SFW.
Suggestions run offline and refresh with Panora updates. [Page one](https://wallhaven.cc/tags/tagged) · [Page two](https://wallhaven.cc/tags/tagged?page=2)
