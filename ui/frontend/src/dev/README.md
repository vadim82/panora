# Browser-only fixtures

The `canyon-*.png` images are landscape crops of the project-owned
`assets/branding/panora-logo.png`. The fixture images and mock bridge are
excluded from production builds. Use `&previewShape=square` or
`&previewShape=portrait` to check the image-action placement. See [branding](../../../../assets/branding/README.md).

Open `/?fixture=commons`, then **Sources → Add source → Wikimedia Commons**.
Choose **Search Commons**, enter terms or a category, and press **Search Commons**
to review the simulated results and approve files.
